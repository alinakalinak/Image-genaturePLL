# Project 02 - Signature Verification

ساختار اولیه پروژه تشخیص اصالت امضا با دیتاست UTSig.

- `data/raw/utsig/`: دیتاست اصلی UTSig
- `notebooks/common/`: EDA و preprocessing
- `notebooks/machine_learning/`: مسیر Machine Learning
- `notebooks/deep_learning/`: مسیر Deep Learning
- `src/`: کدهای نهایی
- `models/`: مدل‌های ذخیره‌شده
- `backend/`: FastAPI
- `frontend/`: رابط کاربری
- `storage/`: آپلودها، predictionها و feedback

فعلاً دیتاست UTSig را داخل `data/raw/utsig/` قرار بده.
